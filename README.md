# Insure Landing Page

### Frontend Mentor Challenge

This project is a solution to the [Insure landing page challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/insure-landing-page-uTU68JV8). The challenge was to build out the landing page and get it looking as close to the supplied Figma design as possible.

Users should be able to:

* View the optimal layout depending on their device's screen size, with layouts for mobile, tablet, and desktop
* See hover and keyboard focus states for interactive elements

### AI Experiment

This project is also an experiment in writing all of the HTML, CSS, and JavaScript with AI. The implementation and subsequent code changes were generated using Codex, guided by human instructions, design reviews, and feedback.

The goal is to explore how closely AI-generated frontend code can reproduce a supplied design, including responsive layouts, decorative patterns, and accessible navigation, and how much review and iteration are needed along the way.

The design and original visual assets come from the Frontend Mentor challenge. DM Serif Display and Karla are loaded through Google Fonts.

#### Languages

* HTML
* CSS
* JavaScript

#### Running the Project

Open `index.html` in a browser or serve the project with a local development server. No dependencies or build step are required. An internet connection is needed to load Google Fonts.

Links without a supplied destination are placeholders.
